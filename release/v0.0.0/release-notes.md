# iLLM v0.0.0 Bootstrap Lab

Implements the offline bootstrap lab, deterministic toy scheduler, canonical capture, transactional R0/R1 replay, bounded asynchronous best-effort exporters, sealed platform evidence, rollback rehearsal, and full release-bundle verification.

Learning checkpoint: inspect each scheduler step, replay facts, reproduce state, then corrupt a copied capture to observe rejection. The immutable v0.0.0 tag preserves this CPU-only foundation before real model execution is added.
