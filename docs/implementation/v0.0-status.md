The local Windows/WSL qualification and the CI matrix each seal a
self-verifying platform artifact containing the
ToolchainManifest, JUnit report, quality report, and replayed capture. The
artifact can only be merged by `scripts/merge_v00_qualification.py` when its
project-root, bootstrap, and lock digests match this release source.

The `v0.0.0` tag is the first learning checkpoint. Its release bundle has
`SHA256SUMS.json` coverage and can be verified after checkout without using the
original author's environment paths. Bootstrap must still create a new local
environment for executing commands. V0.0 is CPU-only and makes no real-model,
GPU, or inference-performance claim. Follow the [release learning index](../releases/README.md)
to compare this checkpoint with later versions.
